# Independent audit of source-to-function reviews

16 November 2026. The reviewed crosswalks are **conditional hypotheses for the user's own harness**, not validated equivalences, paragraph gold, trained classifiers or changed catalogue rules. The inspection below covers the four crosswalk JSONs and the scientific label-count receipt as they existed during this audit; later synthesis and normalized receipts require a separate read. No upstream code was executed and no pickle was opened.

## Material constraints for integration

1. **Preserve GUM tree syntax.** Independent XML parsing of the pinned `rst/rstweb` directory found 301 RS4 files. All 32 proposed eRST relation labels occur; an additional `relname="span"` appears 26,862 times as a structural attachment marker. It is not a 33rd discourse-function category, but discarding it breaks reconstruction of the structure. Parse relation direction, nucleus/satellite, endpoints, groups and secondary edges before any alignment. A relation between EDUs or larger spans is neither a paragraph label nor evidence that a particular paragraph performs a harness function. A matching label or possible mapping is coverage of a *hypothesis*, not measured recall or semantic coverage.
2. **Artifact status is not dataset status.** `acquisition.json` marks the BUILD GitHub archive downloaded; it contains 93 files and a README codebook but does not establish that the hosted train/dev data were acquired. Their separate acquisition records both return HTTP 401. PERSUADE 2.0's downloaded GitHub archive contains only README and three rubric PDFs. The later `followup-acquisition.json` records a separate downloaded 616,894,963-byte training CSV and test ZIP; a bounded header and row-shape check confirms the training file contains essay and discourse fields. It also contains demographic and disability-status columns: minimize access and retain only fields necessary for the task. Initial ECHR `master` acquisition failed HTTP 422, but the follow-up successfully downloaded the `main` archive with 1,997 regular files, including token/BIO CSVs; review the actual data and rights before claiming task-specific counts. SciPara's archive includes one pickle and notebook; its contents were not safely inspected and its annotation/source license remains unverified. Do not claim local usable annotation rows from these packages without an additional verified receipt.
3. **Source names and serialized values are different layers.** AZ's seven paper names correspond to abbreviated `AZ` XML attributes; the independent recount below agrees with the receipt. MuLMS guide names such as `EXPERIMENTS/PREPARATION` correspond to the exact serialized `Exp_Preparation` value, and the detailed receipt preserves both. BUILD's prose has `PRE_RLEIED` versus table `PRE_RELIED`; no unavailable file has settled actual serialization. Preserve variants verbatim and document any normalization instead of silently altering source labels. Structural, experimental and annotation layers are not interchangeable.
4. **Counts have different denominators.** Independent inspection of 50 XMI files in the nested MuLMS ZIP reproduced the receipt's raw per-attribute counts, including `Exp_Preparation` 1,470 and `Background` 3,159. These are annotation elements, potentially overlapping, and include structural layers; they are not unique sentences. The paper's 962 projected `Exp_Preparation` sentence labels are a different measure. AZ's counts include abstract/body items. Webis rows, continuation markers, and source-reported units also have differing meanings; paragraph separators are not necessarily paragraphs. The related GUM/GDTB, WLP releases, and overlapping/same-source datasets cannot be added as independent evidence.
5. **License each layer.** The downloaded GUM `LICENSE.md` explicitly grants its annotations CC BY 4.0 but lists different text licenses, including noncommercial restrictions for some essays, letters, fiction and WikiHow. Do not interpret the annotation grant as permission to redistribute every underlying text or use it commercially. MuLMS metadata records paper-level rights while the project distinguishes corpus from AGPL software. Indian-50's MIT repository license does not independently settle judgment text rights. PERSUADE's README asserts CC BY 4.0 for data, but associated prompts and original materials still need review for the intended use. Verify rights for the actual intended format, reuse and distribution.

## Source identification error

The follow-up acquisition record `scidtb-paper` mislabeled ACL [D18-1388](https://aclanthology.org/D18-1388/), which is a political ideology detection paper. The SciDTB paper is ACL [P18-2071](https://aclanthology.org/P18-2071/), correctly cited in the scientific crosswalk. The subsequent [identity correction receipt](../identity-corrections.json) records the correct PDF separately and excludes the earlier file. Preserve the failed identity as provenance; do not treat the earlier receipt as the SciDTB paper.

## Independent checks

- **AZ:** regex of single-quoted `AZ` attributes across the 80 actual `.az-scixml` files yielded `OWN` 8,623, `OTH` 2,019, `BKG` 789, `CTR` 600, `AIM` 314, `BAS` 246, `TXT` 227; these match [scientific-observed-labels.json](scientific-observed-labels.json). This checks serialization and counts, not whether the proposed crosswalk is semantically valid.
- **MuLMS:** Python standard-library ZIP/XML parse of 50 `.xmi` files in `data/mulms_corpus.zip` reproduced every reported `ContentInformation` and `StructureInformation` attribute frequency. Values `MEASUREMENT`, `QUAL_MEASUREMENT`, and `Confict of Interest` appear exactly as recorded; they must not be silently recoded as guide-defined argumentative zones. `None` values and non-AZ layers require separate treatment.
- **GUM:** local RS4 labels match the crosswalk vocabulary, with the `span` qualification above. Observing labels in 301 graph files does not establish 301 complete eligible documents or prove original source rights.
- **Indian-50:** the downloaded `data/text` directory contains 50 `.txt` files. Their existence and the paper's label descriptions do not independently establish every text's completeness, label distribution, sentence-to-paragraph alignment, or legal rights.
- **Argument and legal reviews:** the Webis crosswalk explicitly distinguishes `continued`, `no-unit`, paragraph markers and argumentative categories; the microtext crosswalk distinguishes ADU and document stance and acknowledges relation-to-relation edges. The ECHR review separates actor and argument layers and does not invent support targets. Retain those safeguards in every downstream normalized output.

No source-to-harness mapping has been evaluated on independently coded, complete realization spans. A list of all twelve functions occurring in candidate mappings cannot establish that all twelve are represented, that the resources cover a chosen form, or that target-function frequencies can be imported. Keep unsupported cases unresolved, preserve source units and attribution, and measure boundary and label agreement independently on a rights-cleared sample before claiming adoption validity.

## Addendum: merged review and source profiles

The six merged source reviews have matching SHA-256 references; the JSON and CSV contain 159 rows with unique IDs and agree on checked fields and candidate-function lists. All 49 rows marked `none` or `relation_only` have empty normalized function-candidate arrays. These checks establish faithful assembly, not validity or coverage of the twelve functions.

A bounded inspection of the first 10,000 PERSUADE training rows found all eight serialized discourse values, including `Concluding Statement` and `Unannotated`; the crosswalk properly retains `Concluding summary` as rubric wording while distinguishing the CSV value. The sampled Indian-50 file contains full serialized legal-role names such as `Facts` and `Ratio of the decision`, consistent with the merged crosswalk’s separate paper acronyms. This is not an independent recount of the entire large CSV.

**GUM profile count basis corrected:** independent parsing found 37,987 segment, 34,367 group and 1,461 secondary-edge elements carrying `relname`. The revised profile separately reports 72,354 primary attachments and 1,461 secondary edges, with 73,815 combined attributes; each combined label count equals the sum of its primary and secondary counts. The 26,862 structural `span` markers are retained in the primary count. The earlier misleading parent-attachment description has been corrected.

The PERSUADE profile flags 60 train and 37 test offset bounds cases for investigation. Bounds validation alone cannot establish text alignment, Unicode indexing conventions or semantic label validity; no judgment of invalid data or profile reliability follows without resolving the check.
