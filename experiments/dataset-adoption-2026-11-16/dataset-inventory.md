The [28-entry codebook index](codebook-index.md) links original guides, rubrics, schemas and methods papers. [Original-unit profiles](source-profiles.json) give exact counting methods and release paths for eleven selected resources/layers. Some other downloads are inspected at package/schema level only. The [crosswalk](crosswalk.csv) is definition-based, not an automatic relabeling of every row.

BAWE metadata retain combined family values such as Essay + Critique rather than forcing each assignment into a single type. Those are source-specific student-writing labels, not an adopted replacement for our hierarchy.

Rights apply separately to software, annotations and original documents. Read the license and provenance included with each release before packaging content in a distributable plugin. Several collections carry noncommercial or share-alike terms. Public readability alone is not a redistribution grant.

[Remaining access and format gaps](remaining-access.md) distinguish unavailable data, methods-only papers and unopened serialization. No upstream training code or serialized Python objects were executed.
