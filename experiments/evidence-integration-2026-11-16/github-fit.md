# How the studies fit the reusable research and code

The earlier acquisition already supplied annotated text, codebooks and source formats. These papers mainly add outcome evidence, genre detail and methodological guidance. The product should retain that separation: source annotations can supply examples and hypotheses; reader or author evaluations test whether using them actually helps.

| Resource | Current access/inspection | Useful next use | Boundary |
| --- | --- | --- | --- |
| AcaWriter | Pinned source and thirteen feedback-rule files downloaded in dataset-adoption cache | Borrow rule/condition/message separation | Existing institutional cues and stock stems are not our author's voice or validated form rules |
| Research Writing Tutor | Official descriptions and methods papers; no verified open-source application/full-corpus release | Use goals/examples/feedback as a learning-process precedent | Do not claim its complete software/corpus is installed or publicly imported |
| GUM / eRST | Original graphs, XML and relation guidelines local | Test source/target, attribution, contrast and evidence display | Original units, secondary edges, grouping and text rights remain explicit; no paragraph-gold equivalence |
| BAWE / READMEClassifier / DITA | Source assignments, saved READMEs, codebooks and standard local | Expose family purpose, section jobs and procedure alternatives | Student assignments, section labels and normative elements have different units and roles |
| AZ / MuLMS / SciDTB / SciPara | Most source annotations and guides local; SciPara serialization remains unopened | Compare scientific roles and boundary cases | Native labels and spans remain separate; a downloaded object is not a validated mapping |
| Webis / microtexts / legal corpora | Source argument and attribution structures local | Make examples, opposing voices and claim links inspectable | Evidence type is not evidence adequacy; some schemes omit targets or use edge-to-edge attacks |
| [Winning Arguments / ConvoKit](https://convokit.cornell.edu/documentation/winning.html) | Original paper fully reviewed from recovered author copy; official current documentation inspected | Add an audience-response/context research layer to existing argument annotations | Converted corpus, original paper split and selected paired task differ; repeated pairs/missing comments require grouped handling; no causal phrase recipe |
| [Sentence concreteness](https://github.com/maubinle/sentence_concreteness) | Official README and MIT repository notice inspected; no installation or runtime test | Candidate descriptive feature for scoped title comparisons | Averaging word ratings and assigning named entities maximum concreteness is a method, not a universal specificity or quality measure; dependencies/data rights separate |
| P08 narrative instruments/data | Official rating questions/instructions, raw CSV, journal table and R script downloaded; aggregate structure inspected, script not executed | Compare reader-rated connectedness/appeal with source functions and section purposes | 5,614 raw judgments over 802 units, seven per unit; paper's 732 abstracts are post-QC. This instrument does not annotate our narrate realization spans |
| Existing local checkers and edit tools | Current code/documented behavior available; unchanged by this work | Prototype source-bound local edits and actual declared constraints | Counts, hashes and diffs do not establish meaning, authenticity or reader benefit |

P08's native dimensions are setting, first-person narrative perspective, sensory language, conjunctions, connectivity and appeal. They cross several of our functions and relations; reducing them all to `narrate` would erase their definitions. The raw supplemental file includes contributor fields, which were not propagated into derived review outputs. Its original R script is evidence about the method, not a program we ran. Source receipts are in [supplement-attempts.json](supplement-attempts.json).

P14's supporting methods were also retrieved from the official publisher after a previous web-tool fetch failed. This upgrades method access, not evidence of a causal intervention or reproduction of the Scopus dataset. [The updated review](reviews/agreement-writing-rules.md) preserves the selection, model and overlap details.

The professional memo/proposal and authentic personal-writing gaps remain. Existing annotation coverage and study populations cannot silently fill those gaps. Build the author's workflow around reusable pieces, retain source scope, and collect or annotate only what is needed to test transfer and missing distinctions.
