# Rule decisions from the supplied evidence

These twelve integration proposals preserve the existing skills and accepted foundations. They are not twelve new universal prose rules. Several reaffirm existing guidance; the main additions concern durable context, source scope, visible structural choices and measured review behavior. [Full records](rule-decision-ledger.json) include source pages, current files, triggers, counterexamples and the model/code/author boundary.

| ID | Decision | Disposition |
| --- | --- | --- |
| C01 | Bind language choices to reader knowledge | reaffirm principle; add durable runtime context |
| C02 | Check how an explanation is encountered | refine reader edit |
| C03 | Keep the intended outcome with every evidence-based suggestion | reaffirm measurement boundary; add rule metadata |
| C04 | Show section jobs and alternative structures | reaffirm accepted hierarchy; implement visible choice |
| C05 | Preserve supported force while allowing truthful emphasis | reaffirm fidelity; implement focused change review |
| C06 | Evaluate titles against the promised contribution | refine purpose-based title review |
| C07 | Use examples and narrative as purposeful options | reaffirm author voice and provenance |
| C08 | Keep surface metrics descriptive unless a real constraint applies | reaffirm existing rule |
| C09 | Retain who says what and how contributions connect | refine source representation |
| C10 | Measure labels, spans and reader benefit separately | refine research protocol, not routine prose |
| C11 | Give only assistance that resolves the current writing problem | new runtime hypothesis; no claimed empirical win |
| C12 | Preserve the author thought and scope of accepted decisions | new durable workflow hypothesis; existing voice principle |

Hard enforcement belongs to explicit task constraints and mechanically verifiable structure. Source-derived associations provide conditional review guidance. Author preferences retain their own authority and scope; they need not be justified by a population study. The model evaluates uncertain meaning and applicability; the author controls intended substance and voice. No proposed rule is supported merely because its proxy predicts popularity.
