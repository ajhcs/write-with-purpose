# Retained documentation sources: reanalysis method

This pass processes all 494 retained source records in `experiments/form-corpus-2026-11-16/explanation-tutorial/records.jsonl`, including 469 originally screened candidates, 23 originally excluded as short or fragments, and two excluded for a conflicting declared type. Original screening status is preserved. `short_under_120_prose_words` is a separate flag recomputed with the common measurement core; it is not a genre exclusion. A filename-based index flag identifies possible navigation pages, but is not a reliable navigation classifier. No source is accepted as an example of its proposed form: `form_candidate` is a discovery label and remains unverified.

The source is entirely software documentation, at the pinned commit shown in each record. It is a current-version collection as retrieved on 16 November 2026; individual publication years are unknown, and it is not a historical or cross-domain sample. Source type, repository, URL, commit, attribution, license metadata, original status, retrieval date, and source-specific metadata are retained from the original record. There are 242 explanation-labeled and 252 tutorial-labeled source records before the original exclusions; these labels establish neither purpose nor quality. See the prior collection's `summary.md` and `sources.json` for acquisition, selection, archive provenance, licenses, and failed discovery attempts.

For each record the script finds the retained bytes under `/workspace/tmp/builderbob/writing-corpus/explanation-tutorial` using SHA-256 of its original raw URL as the cache filename. It hashes the actual file bytes and stops on any mismatch with the original source SHA-256. All 494 matched. It uses no network, does not import or execute source Python, and stores extracted blocks separately under `/workspace/repos/builderbob/.writing-corpus-cache/analysis/docs/`. The JSONL contains metadata, aggregate metrics, per-document arrays and heading text, but no full extracted prose. Reproduce with `python3 experiments/corpus-analysis-2026-11-16/analysis/analyze_docs.py` from the repository root, with the retained cache and installed `markdown_it` available. `metrics.py` supplies the shared token, sentence, summary and document measurement definitions.

The 281 Markdown pages use CommonMark tokenization after YAML-style front matter removal. Soft and hard line breaks become spaces; inline code and link display text are retained, while HTML tokens and link destinations are omitted. Standalone Hugo shortcodes are omitted; inline shortcodes retain an explicit `text=` label where present and otherwise are omitted. These approximations do not render template content. The 60 notebooks are processed in cell order: Markdown cells are parsed, code cells represented as code blocks, and outputs omitted. The 93 reStructuredText sources are converted heuristically: recognized underlined headings and inline roles are approximated, while directives and their indented bodies are omitted. The 60 Sphinx Gallery Python sources contribute only a module docstring and top-level comment tokens, extracted via `ast.parse` and `tokenize`; their rendered order and code structure are not faithfully reconstructed. Markdown embedded in notebook cells can itself contain code blocks, so the resulting code-block count is not simply the number of code cells. Tables, directives, templating, conditional content, includes, cross-references, HTML, and markup extensions are not fully rendered or resolved. A detected template or transclusion is flagged, but absence of that flag does not prove completeness.

All records are marked `source_partial` and `profile_eligible: false`: neither rendered-page equivalence nor paragraph and sentence boundaries have been verified. Metrics are exploratory extracted-source measurements and must not be used to bootstrap form norms, pooled distributions, or comparisons across formats. Headings and section intervals are parser artifacts, not necessarily semantic sections; lists, code and quotes are counted separately from paragraph prose. Publication-specific and document-specific distinctions remain unresolved. The prior procedure and reference collections retained derived counts but not their HTML bodies; they cannot be reanalysed with these common extraction and measurement methods from the retained evidence. They remain a coverage gap, and no network refetch was performed.
