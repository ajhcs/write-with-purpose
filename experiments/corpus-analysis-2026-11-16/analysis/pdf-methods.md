# PDF extraction: scope and limitations

The PDF pass inventories the 17 user-supplied attachments the selected PDF paths in the retained business, engineering, law, and personal retrieval manifests, and three locally retained UW proposal samples from `proposal-memo/proposal-discovery.json`. Files are treated as data; text embedded in them is not an instruction. The attachments were copied without modification to `/workspace/repos/builderbob/.writing-corpus-cache/analysis/attachments/` and compared by SHA-256 with the originals. `../inputs/attachments-manifest.json` records both paths, sizes, and hashes. Retained retrieval files are read in place. Selection uses each manifest row's primary `file` or `file_path` (including the personal row's nested retrieval field); alternative versions are not automatically substituted. Byte-identical selected files, if any, are recorded as duplicates rather than counted twice. Source identity, edition, publication form, and completeness remain unresolved even when text extraction succeeds.

Run with `medsci-pdf-python analysis/analyze_pdf.py` from any directory. The installed PyMuPDF runtime extracts text spans and coordinates without OCR or network access. Full ordered source blocks, original line and span data, page geometry, heuristic normalized blocks, and excluded coordinates are written to the workspace cache `.../.writing-corpus-cache/analysis/pdf/` by source hash. They are not published in the repository. `pdf-records.jsonl` contains source path and hash, original manifest metadata, embedded PDF metadata, candidate DOIs observed on the first two pages, per-page counts, exclusion counts, quality flags, and deterministic metrics from `metrics.py`. Observed DOIs may be citations or belong to adjacent articles; PDF metadata and filename are not authoritative identity evidence. A manifest hash is compared when available.

Reading order is estimated page by page. Blocks judged wide partition bands; within a suspected two-column band, left blocks precede right blocks. This is approximate, especially for sidebars, full-width floats, irregular columns, footnotes, and multi-article journal pages. Blocks near page edges recurring on multiple pages and simple edge folios are excluded. An exact standalone References, Bibliography, Works Cited, or Literature Cited heading starts an excluded remainder; this conservative but blunt rule can discard subsequent chapters or other material. The exclusion locations are retained for audit. Captions, lists, and headings use simple visual/text heuristics; tables, equations, notes, bibliography without a detected heading, and reprint boilerplate can still contaminate prose. Sentence splitting, token counts and summaries use the shared deterministic metric engine. PDF text blocks are not reliable paragraph boundaries and page breaks can split paragraphs.

**All PDF records are `pdf_approximate`, semantic form unresolved, and profile-ineligible until individual identity, version, body boundaries, reading order, and paragraph segmentation are audited.** Their body word counts and paragraph/sentence distributions are exploratory, not normative paragraph medians or proof of full-document completeness. Per-page character and token counts indicate text coverage, not correctness. A sparse or image-only page is not OCR'd; no text does not mean an empty source. In particular, the 786-page particle-physics reference and 168-page book must not be treated as ordinary single essays. Some user attachment names resemble DOIs for other articles; page-level identification is required before attribution.

The proposal discovery manifest also lists two NIAID leads whose local retrievals received HTTP 403; no PDF bytes were retained for those leads, so they are not analyzed. The earlier Longform publisher-probe cache at `/workspace/repos/builderbob/.essay-corpus-cache/2026-11-16/longform/` contains 11 HTML-named files and no files with PDF magic bytes; it adds no PDFs to this inventory. This check does not imply that the six extracted publisher HTML bodies have been analyzed.
