# Local JATS XML extraction and measurement

This is a mechanical, descriptive pass over every XML file in the five local source roots, including cached candidates that were excluded, bypassed, or not selected in earlier branch samples. A measured file is **not** a verified example of its inferred form or a recommendation. The original four roots contain 2,648 files: 903 case/protocol, 459 empirical/methods, 899 narrative/scoping, and 387 systematic-review. The additional Europe PMC editorial/personal-narrative discovery cache contains 594 XML files. The combined output retains all 3,242 source files and their branch provenance. The new cache has 590 files with extracted prose, three with a body but no extracted prose, and one without a body; its indexed form labels are discovery signals, not eligibility decisions. Across all roots, 3,239 files have `<body>` elements, 3,228 have at least one extracted prose paragraph, and 14 are excluded; no parse errors occurred. These numbers retain both copies of one PMCID with the same SHA-256 (PMC7083240); they are source-file totals, not unique-work totals. DOI-level deduplication remains separate. The first four roots still have 2,638 measured files and 10 excluded: two lack a body, seven contain preformatted body content with no prose paragraphs, and one has no extracted prose paragraphs. An existing body element, preformatted text, and extracted prose are separate conditions. All records remain in the JSONL, with status and reasons.

`analyze_xml.py` reads only these local files and prior local manifests; it makes no network requests and needs Python's standard library and adjacent `metrics.py`. Run it from any directory using `python3 experiments/corpus-analysis-2026-11-16/analysis/analyze_xml.py`. The JSONL is one record per source file, with source path and SHA-256. Metadata comes from JATS, including the article DOI rather than a filename or reference DOI; all JATS publication dates are retained and the earliest four-digit JATS year is an approximation of first publication year. Matching prior candidate/manifest metadata is preserved separately, not treated as confirmation of suitability. Form labels are provisional title and JATS category/type signals: protocol suppresses inferred review labels, and an unspecified label remains when evidence is insufficient. Branch membership does not establish form or clinical scope. Dates, types, author names and journal fields can be incomplete or ambiguous.

The parser walks `<body>` in source order, excludes sections whose headings exactly match its explicit case-insensitive administrative list, and skips abstracts, reference lists, captions, figures, tables, displayed or inline formulas, supplements, boxed text, labels and footnote groups from prose. Other heading variants can escape the filter, and a matching heading may occasionally be substantive. Headings are retained as ordered blocks; sections have stable per-file IDs, parent IDs and levels so duplicate names remain distinct. Paragraphs go to their closest section; the shared metrics' section shares use direct assignments divided by extracted prose words, and do not roll child totals into parents. Unsectioned prose is retained. Inline text and tails are joined without adding artificial spaces, while cross-reference display text is removed and is not converted to numerical prose. Nested paragraph-like elements and lists are traversed separately to avoid double counting. List-item, code, quote and caption blocks are separated from prose; preformatted text is separately counted, because preformat markup alone does not establish code. Some mixed or unusual JATS structures may not be reconstructed as intended.

Shared `metrics.py` defines word tokens, sentence splitting, descriptive quantiles and block measures. Its word counts and sentence estimates are mechanical, and technical abbreviations, unusual punctuation or markup can introduce errors. Title, abstract, captions, reference entries' text, excluded administrative text and preformatted text have separate word counts. Reference entries count `<ref>` children of reference lists in the body or back matter of the main article. A section exactly headed References or Bibliography is excluded from prose and heading counts; unstructured reference paragraphs do not yield structured reference-entry counts. Figure, table, list, external-link and bibliographic-cross-reference counts are raw body element counts; the latter counts marker elements, not cited works, and all these body object counts can include administrative or excluded structures. They do not establish examples, evidential purpose or placement. F07 roles and F09 communicative functions require review; they are not inferred here. Citation cross-references whose types are absent or nonstandard, unmarked citations, graphics represented by other tags, and objects outside the body are not captured by these object counts.

Extracted ordered block text is stored outside the repository under `/workspace/repos/builderbob/.writing-corpus-cache/analysis/xml/<source-branch>/<filename>.json`, alongside source hash and path; source-branch directories prevent overwrites if caches later share an identifier. The repository contains source metadata, derived metrics and headings, rather than full paragraphs. One PMCID and identical source hash occur in two branches; both source files are retained. This does not establish DOI or work-level uniqueness, and cross-format or DOI deduplication is a separate step. The source texts and licenses remain governed by their source terms.

## Two administrative exclusion checks

The earlier empirical-methods manifest recomputed administrative exclusions independently. For PMC1904193 its previous main/admin word counts are 2,580/116; this pass records 2,579/116, with Competing interests, Authors' contributions and Pre-publication history excluded. For PMC2277487 the earlier counts are 4,319/236 and this pass records 4,318/236, excluding Acknowledgments. They do not validate all XML structures or administrative heading variants.

## Article structure check

PMC10008412 stores its author role on `<contrib-group content-type="author">`, rather than on each contributor, and places its reference list within body sections. The revised parser records five authors and 29 structured references (864 reference words). It excludes the exact administrative heading Ethics statements, which contains Patient consent for publication, and retains the substantive Ethics and dissemination section. This check does not establish that every publisher's author or reference structure is covered. The wider collection is biomedical-heavy, but individual domain classification remains unverified; no blanket clinical classification is applied.
