## Contradictions and overextensions retired

- **R01:** Global smallest-diff interpretation, defect-only trigger, serial one-at-a-time constraint and mandatory exact-plan workflow for every saved edit. Boundary: Correction-only/fixed-order/protected wording constraints remain; improvement does not require a rewrite if no candidate earns its tradeoff.
- **R02:** Treating a cautious model bridge as sufficient grounds for an author thesis; preserving a revisable recommendation as though it were a fact. Boundary: Only materially blocking evidence/intent leads to a question; unaffected work continues; no exhaustive map for ordinary connective edits.
- **R03:** Mandatory two drafts, superficial renamed alternatives, analytic productivity requirement for artistic effects, minimum footprint as merit. Boundary: Comparison is conditional and proportional; unclear effect/original can stand; model judgment is not reader success.
- **R04:** Forcing exhaustive runtime labels or dismissing research disagreement because no edit would change. Boundary: Twelve IDs retained; original source labels/units stay distinct; presence/adequacy/truth and anchors/full extents separate; no new validator or gold claims.
- **B01:** Inferred literal locks from meaning preferences; equating strangeness with intended voice. Boundary: Approved mandatory style/article copies unchanged and identical; supported correction of erroneous or overstated source claims remains contextual.
- **B02:** Source sentence stems, platform-based form defaults, observed medians as targets. Boundary: No required printed headings, taxonomy quiz, new family inventory or numerical profiles.
- **B03:** Generic pass claims, stale receipt reuse, false body-scope inference and file-hash claims about later chat delivery. Boundary: Scripts unchanged: exact literal and max-word/growth contract; other real constraints need separate checks; editor can use an available counter without writer helper.
- **B04:** Homework after a rationale request or attempt-first blocking a worked solution. Boundary: No acceptance-as-learning claim or mandatory exercise.
