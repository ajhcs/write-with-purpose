# Form in the writing harness

Proposal for discussion, 15 November 2026. The profile names and behaviors below are design proposals. They are not installed writing rules or a universal classification of writing.

Form should describe the kind of contribution a reader expects and how the writer develops it. It should influence the writing process, the organization of the result, and the evidence used to judge it. Selecting a form should produce an intelligible writing plan before it produces prose.

The existing skills provide a useful foundation: select the contribution, preserve the author's voice, organize for the reader, and assess conformance, correctness, and usefulness separately. The proposed layer makes the form-specific decisions visible and executable where appropriate. See [the existing structure guidance](../../skills/write-with-purpose/references/structure-and-purpose.md).

## 1. What the current selector conceals

The initial explorer puts personal blog, technical explainer, systematic review / meta-analysis, manual, and README in one list. These are useful starting phrases, but they describe different things:

| Starting phrase | What the harness should resolve |
| --- | --- |
| Personal blog | A publishing context plus a possible personal voice. The piece could be a reflective essay, argument, explanation, or another form. |
| Technical explainer | A form aimed at understanding, plus a subject and a reader's existing knowledge. |
| Systematic review / meta-analysis | A review form and a possible statistical synthesis method, with distinct evidence dependencies. |
| Manual | A larger document that can contain tutorials, procedures, explanations, and reference material. |
| README | A recognizable composite genre with an orientation function, usually combining purpose, getting started, and routes to further information. |

Keep these familiar phrases as entry points. Resolve them into a visible plan without making the author learn our internal terminology. GitHub's own README guidance identifies several reader needs within this one document, including purpose, first use, and help. [GitHub](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes)

## 2. A manageable starting map

Use five browsing groups. A group reveals its forms when selected; frequently used forms can be chosen directly. These groups organize the interface and do not impose a common outline on their members.

| Browsing group | Candidate forms |
| --- | --- |
| Essays and commentary | Personal / reflective essay; argument / perspective; critical review of a work |
| Explanation and documentation | Conceptual explainer; tutorial; how-to / procedure; reference |
| Research reports | Empirical research report; methods paper; theory / conceptual paper; case report; study or review protocol |
| Evidence syntheses | Narrative / critical literature review; scoping review; systematic review |
| Proposals and decisions | Proposal; decision memo |

This is seventeen candidate profiles behind five choices. The count is a starting hypothesis, not a target. A named academic perspective can specialize the argument profile; grant proposals can specialize a proposal. Different conventions remain explicit even when implementation components are shared.

README and manual remain directly selectable composite presets. A README has its own overall reader task and a suggested sequence of typed sections. A manual has a navigation structure and pages with their own forms. A dissertation could use the same composition mechanism later, with institution-specific requirements.

For documentation, Diátaxis provides a useful established distinction among explanation, tutorial, how-to, and reference. In particular, tutorials develop competence through a managed learning experience, while how-to guides support accomplishment of a task. That distinction is not equivalent to beginner versus advanced. [Diátaxis](https://diataxis.fr/), [tutorials and how-to guides](https://diataxis.fr/tutorials-how-to/)

### Deciding when a distinction deserves a profile

1. **Another name for the same task:** add an alias and show the resolved form.
2. **A change of outlet, topic, audience, or length:** use the corresponding setting. A specialist blog does not need to become a new form.
3. **A methodological difference within a communication task:** add a study-design or analysis module. An empirical report needs different evidence checks for a randomized trial and an observational study.
4. **A different reader task or composing strategy:** create a distinct form. A tutorial and procedure can share numbered steps while needing different preparation and review.
5. **Several reader tasks in one document:** use a composite preset with explicit section roles.

Test a proposed split with actual examples: would combining the forms repeatedly lead to the wrong opening, missing evidence, an unsuitable sequence, or the wrong reader test? A new name alone is insufficient. Conversely, shared headings are insufficient grounds to merge forms.

## 3. How form affects the rest of the plan

| Element | Form contributes | Another decision still needed |
| --- | --- | --- |
| Purpose | A likely reader task: understand, interpret, learn, act, evaluate evidence, or decide | The particular contribution this author intends |
| Intake | Questions and source material appropriate to that task | What the author actually knows, believes, observed, or has evidence for |
| Structure | Useful rhetorical moves, dependencies, and alternative sequences | Which structure develops this particular thought; any venue requirements |
| Length | A basis for budgeting: whole argument, learning episode, task, reference entry, or manuscript component | Actual scope, venue limit, reader needs, and author preference |
| Reading demands | The kind of reasoning or action the reader must follow | Subject familiarity, vocabulary, numeracy, reading fluency, and use context |
| Terminology | Terms introduced by the form or method, and conventions for stable names | The domain vocabulary and which concepts this audience already knows |
| Register | Useful stance and conventions: reflective, explanatory, instructional, analytic, or deliberative | The author's voice and the publication's actual rules |
| Evidence | Appropriate support and required links to underlying work | Whether that support exists and warrants the claim |
| Layout | Relative value of headings, lists, tables, figures, cross-references, and navigation | Output medium, accessibility, and publication layout |
| Coaching | The next writing move worth practicing | The author's current difficulty and preferred level of assistance |
| Checks | A relevant set of mechanical and editorial assessments | Which are executable, which require judgment, and which requirements are mandatory |
| Completion | A reader task against which the result can be evaluated | Actual author acceptance, reader feedback, and any external submission requirements |

Form can suggest an audience, but must not silently set one. An advanced researcher can be new to a neighboring subject. A personal essay can address experienced specialists. Reading level should therefore be a record of assumed and taught concepts, supported by prose and numerical explanations, rather than a single school-grade score. CDC explicitly notes that readability formulas omit audience, purpose, and many factors that affect comprehension. [CDC](https://www.cdc.gov/ccindex/tool/index-different.html)

Each term can have a concept, a preferred name, accepted variants, and an audience treatment: assumed, explain on introduction, or link to a definition. Scientific and technical terms should retain their meaning. A form change can alter the terms needed without making established terminology wrong.

## 4. Academic writing needs more than one template

The harness should distinguish manuscript form, research design, analysis method, and publication requirements. Medical reporting guidance illustrates this clearly, but those rules should only apply to appropriate work. Humanities, engineering, and other scholarly traditions require their own examples and relevant conventions.

| Academic form | Distinct writing work | Required basis for substantive claims |
| --- | --- | --- |
| Empirical report | Connect a research question, methods, findings, and interpretation | Study records and analysis; reporting guidance selected for the actual design |
| Methods paper | Explain a method sufficiently to understand, reproduce, and assess it | Method definition, assumptions, implementation where applicable, and evaluation |
| Theory / conceptual paper | Develop a model, distinction, or argument and examine its implications | Explicit premises and derivation or reasoning; relevant scholarly engagement |
| Case report | Present a particular case, its course, and the significance that the record supports | Case evidence and appropriate reporting requirements; limits on generalization |
| Protocol | Describe intended work and planned decisions | The actual prospective plan, amendments, and applicable protocol requirements |
| Narrative / critical literature review | Develop an interpretation of a body of literature | A transparent account of scope and source selection; supported synthesis |
| Scoping review | Map the extent and characteristics of an evidence base | Search, selection, extraction or charting records, and an applicable reporting profile |
| Systematic review | Address a defined question through explicit review methods | Search, screening, appraisal where appropriate, extraction, and synthesis records |
| Scholarly perspective | Defend an interpretation or position in an existing scholarly discussion | Accurate engagement with relevant work and appropriately qualified arguments |

ICMJE describes IMRAD as a usual structure for original research while acknowledging other article structures and study-specific reporting guidelines. It is a useful medical publishing source, not a template for every discipline. [ICMJE](https://www.icmje.org/recommendations/browse/manuscript-preparation/preparing-for-submission.html)

Scoping reviews and systematic reviews need distinct profiles because their questions and synthesis aims differ. PRISMA supplies separate guidance for scoping reviews and review protocols. Reporting-item coverage must remain distinct from the quality of the research and its conclusions. [PRISMA 2020](https://www.prisma-statement.org/prisma-2020), [PRISMA-ScR](https://www.prisma-statement.org/scoping), [PRISMA-P](https://www.prisma-statement.org/protocols)

Meta-analysis is a statistical synthesis method. A review may contain one or more meta-analyses, other synthesis methods, or no statistical pooling. The interface can still recognize the familiar request “write a meta-analysis,” then identify the review type and actual analysis. Selecting it introduces dependencies on appropriate data, analysis records, and reporting; it cannot establish that pooling is justified. [Cochrane Handbook, chapter 10](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-10)

## 5. The form profile is a reviewable writing plan

Each profile should supply:

- A reader task and a description of the contribution it can support.
- Relevant intake questions and source roles.
- Several possible structures, expressed as the work each section does. Required headings come from a stated source.
- Evidence prerequisites and links to specialized research or engineering workflows.
- Length guidance with provenance: author choice, venue rule, observed examples, or a provisional estimate.
- Register guidance and a map of where the author's interpretation and expression matter.
- Applicable checks, their scope, and their limits.
- Coaching prompts and annotated examples that explain writing choices.

The plan should distinguish **required**, **recommended**, and **chosen by you**. It should display the source of a requirement or recommendation. For example: a journal's abstract ceiling is required for that destination; explaining a term on first use is recommended for the selected reader; preserving a chosen opening is an author decision. Changing the destination or opening remains possible, but the resulting consequences stay visible.

Typical lengths should be learned from suitable examples, with their population recorded. A collection of web explainers does not establish the expected length of a journal tutorial. A working budget is always labeled as such. When a target journal gives separate main-text and abstract limits, the counter must implement those scopes rather than reuse a raw whole-file word count.

## 6. What a change of form should do

Changing a selection should preview the implications before any draft transformation. The original notes, source records, author choices, and draft remain available.

For a change from personal essay to systematic review, the harness should show:

- **Reusable material:** the motivating observation, relevant references, and the author's question.
- **New work:** a defined review question, appropriate review methods, and the research records needed to support the manuscript.
- **Different claim support:** personal experience may motivate the work; statements about the literature require the review evidence.
- **Different checks:** reporting-item locations, citation resolution, study-flow reconciliation, and consistency with analysis outputs where available.
- **Current state:** which work exists, which remains unresolved, and what can be written honestly now.

A change from tutorial to procedure should instead alter prerequisites, action sequence, handling of variation, and the reader task used for testing. A change of audience should revise explanation and terminology assumptions. A change of assistance mode should revise who drafts which passages. These changes need different scopes of recomputation.

Existing check results become stale when their draft, profile, sources, or relevant settings change. A check result should identify those inputs and its version. Conformance, correctness, and usefulness remain separate.

## 7. Authorial voice and learning

The current approved style reference values concrete relationships, useful context, developed examples, and qualifications attached to their claims. These can carry across forms without importing the example article's shape. [Approved style reference](../../skills/write-with-purpose/references/cole-lyons-style.md)

Track three author contributions separately: ideas and judgments; expression; and choices about organization. A writer can retain a distinctive interpretation while adapting a methods section to disciplinary conventions. The harness should expose meaningful changes to any of these contributions.

Coaching should match the form. An essay may call for a developed observation; an explainer for a worked example; a procedure for a precise action and expected result; a research discussion for an interpretation with a defensible limit. Show why the move helps, invite the author to attempt it, and give focused feedback. Do not require approval after every sentence or measure originality through an automatic score.

## 8. Computable checks and evaluation

Use deterministic checks for declared constraints and structured records: scoped word counts, citation keys, links, exact labels, required identifiers, and numerical agreement with an explicitly selected analysis artifact. Vocabulary and grammar findings remain contextual suggestions unless a requirement is explicit.

Finding a section or a phrase establishes presence, not adequate reporting. Citation resolution does not show that the source supports the claim. Testable software examples require an appropriate execution environment; textual inspection must not be presented as a successful run. Model review can identify candidate reasoning and clarity problems, while the author and relevant readers judge the contribution and usefulness.

The next implementation increment should define the profile schema and exercise a few contrasting cases before building every profile. Use one author-supplied idea for an essay, explainer, tutorial, and decision memo; use genuine research records for the academic trials. Include a manual and README to test composition. The seventeen-profile map supports discovery now; validated production profiles would be developed progressively.

Assess whether the author can explain the proposed shape, start writing a useful passage, understand the reason for an edit, and carry that writing move into another piece. Also assess whether a reader can perform the intended task and whether explicit requirements are met. The taxonomy earns its complexity through those outcomes.
