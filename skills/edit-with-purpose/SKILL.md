description: Review and revise an existing prose draft for usefulness, clarity, flow and fidelity. Use for an editorial pass, including an independent review; compose new drafts with a writing skill.

Produce the best edited version for the author's intended use. Follow the actual brief, scope and prose preferences. Review information selection and expression as well as recoverable meaning. Correct or understandable prose can still burden the reader through repetition, indirect wording, unnecessary teaching or disrupted flow. Preserve effective writing when it is the stronger version; an unchanged result is valid after considering those editorial choices.

For a requested independent pass, use a fresh agent context when available and authorized. Supply the draft, relevant brief and author constraints, and this skill. An agent already assigned that fresh context performs the review directly. Keep the writer's rationale and previous review verdicts outside the first reading. State a limitation if a fresh context is unavailable; a separate skill name alone establishes no independence.

Read the draft in its intended position and attempt the reader's task. Use supplied surrounding context when editing a fragment. Recover the point, reasoning and intended action, then examine how naturally and economically the passage delivers them. Consider what belongs in this piece: retain the selected claims and context the task needs, rather than treating every true detail in the draft as required. Preserve useful framing and precise terms while making their relationships plain. A paragraph need not repeat context the reader already has.

Make a concrete revision where it helps. Try a deletion, combination or clearer connection and compare the resulting passages. Consider paragraph flow as well as individual sentences: related clauses can share context, and a brief definition can be read with its term. Keep ordinary reasoning implicit when the reader can follow it; explain a difficult inference or a calculation the task requests. A final observation can complete the point. Preserve purposeful repetition, rhythm and emphasis. Changes to voice or form need a benefit for this piece.

Check meaning separately. When sources are supplied in stages, complete the first reader edit before opening them. Compare the revised claims with the relevant evidence, preserving necessary attribution, uncertainty, conditions, chronology and quantitative relationships. Distinguish an omitted detail from a misleading omission. Correct a substantive error when the source supports the correction; identify consequential unresolved questions. Report the scope actually checked: source fidelity alone does not establish factual truth. Missing sources leave factual validation unavailable.

Consult a resource only for the current issue:

- For a contested concept, assertion state, value binding or obligation, read [Technical meaning](references/technical-meaning.md).
- For requested exact observations, read [Mechanical checks](references/mechanical-checks.md). The existing writer's checker is optional support, not a dependency for editing.

Deliver the edited text and only material change notes the task needs. Preserve the original when editing a file unless authorized to replace it. When assessment is requested, report conformance, correctness and usefulness separately, with specific evidence; a clean rule check is not a usefulness judgment. Complete one editorial pass and its meaning check. Further work needs a particular unresolved issue or the user's request, rather than a quota of changes or automatic rewriting loop.
