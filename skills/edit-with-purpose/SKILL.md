Improve the author's existing prose through targeted changes. A request to edit a paragraph identifies the scope to inspect; it does not authorize regenerating that paragraph. Keep effective language, precise terms and the author's voice. Follow an explicit request for a substantial rewrite when one is given.

For a requested independent pass, use a fresh agent context when available and authorized. Supply the draft, relevant brief and author constraints, and this skill. An agent already assigned that fresh context performs the review directly. Keep the writer's rationale and previous review verdicts outside the first reading. State a limitation if a fresh context is unavailable; a separate skill name alone establishes no independence.

Read the whole passage in context before changing its parts. Recover the point, reasoning and intended action. Identify a particular problem in the original: an unclear referent or connection, repeated work, unnecessary explanation, an error, or a break in the paragraph's flow. A generic desire to polish the text is insufficient reason to replace effective wording.

Work from the original with the smallest change that resolves the problem: a word or phrase, then a clause or sentence where needed. A connection can require coordinated changes to adjacent sentences, a join, a deletion or a move. Retain the surrounding language verbatim. Reconsider the paragraph's organization only when local edits cannot resolve the identified problem or the author requests restructuring; make that larger change explicit.

For concision, actively try deleting repeated setup, explanations the reader already has, and observations whose work is complete in an earlier statement. Compare the result with the original before paraphrasing what remains. Preserve useful framing, purposeful repetition and explanations that supply a needed inference or experience. Let a final observation complete its point. Fewer words are a benefit when the passage retains its meaning, necessary context and reading pleasure; neither a reduction quota nor a shorter synonym establishes that benefit.

Make the chosen changes one at a time and reread their connections in the complete passage. This is deliberate editing, not artificial delay or a request for permission after each sentence. For saved UTF-8 text revisions, use [Local edits and change measurement](references/local-edits.md) to apply named changes to a source snapshot and produce a separate candidate. If that tool is unavailable, preserve the local editing method and identify the missing mechanical verification. Count before and after, words inserted and removed, and how much original wording was selected for replacement. These observations expose expansion and broad rewriting; they do not score authenticity or usefulness.

Check meaning separately. When sources are supplied in stages, complete the first reader edit before opening them. Compare the revised claims with the relevant evidence, preserving necessary attribution, uncertainty, conditions, chronology and quantitative relationships. Distinguish an omitted detail from a misleading omission. Correct a substantive error when the source supports the correction; identify consequential unresolved questions. Report the scope actually checked: source fidelity alone does not establish factual truth. Missing sources leave factual validation unavailable.

Consult a resource only for the current issue:

- For a contested concept, assertion state, value binding or obligation, read [Technical meaning](references/technical-meaning.md).
- For requested exact observations, read [Mechanical checks](references/mechanical-checks.md). The existing writer's checker is optional support, not a dependency for editing.

Deliver the edited text and only material change notes the task needs. Preserve the original when editing a file unless authorized to replace it. Show targeted changes or their measurements when requested; ordinary replies need no process log. When assessment is requested, report conformance, correctness and usefulness separately. Complete the local editorial pass, its meaning check and a final reading for flow. Further work needs a particular unresolved issue or the user's request, rather than a quota of changes or an automatic rewriting loop.
